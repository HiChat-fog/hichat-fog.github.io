GitHub Profile 自动化玩具

我的 GitHub 主页仓库 —— 打字动画、贪吃蛇、3D 贡献图、网易云卡片、"正在单曲循环",全部 Actions 自建。

我的 GitHub 主页的源码仓库。上面你能看到的每一个会动的元素——贪吃蛇吃贡献格、3D 贡献城市、网易云周榜卡片、旋转黑胶的”正在单曲循环”、自带摇尾巴小狗的统计卡——都是用自己的 GitHub Actions 定时生成、走 jsdelivr 分发,不依赖任何不稳定的第三方渲染服务。

技术栈:GitHub Actions、SVG 动画(SMIL)、Python、Node.js。
